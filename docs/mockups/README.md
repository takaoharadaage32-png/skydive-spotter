# Skydive Spotter 画面イメージ

デザインツールで作った画面イメージのソースです（専用ランタイム用の形式なので、ブラウザで直接開いても正しく表示されません）。
レイアウト・配色・文言の参照として、マークアップを読んで再現してください。

- `1-input.html`：入力画面
- `2-result.html`：結果画面（地図・Exit地点・パイロット向けの文・Exit順）
- `3-wind.html`：風テーブル画面

配色：背景 #F3F4F1、カード #FFFFFF、文字 #15191E、補助文字 #5A626B、アクセント #C2410C、Level 1 表示 #1D4ED8、GREEN #15803D
フォント：IBM Plex Sans JP（本文）、IBM Plex Mono（数値）
数値はすべて例です（偏角8°W、上空で西風が強まる日を想定）。
